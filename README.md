# EndSemLabExam-kl

This project involves designing a basic object-oriented model to represent the academic and professional structure within an educational institution. It includes three core entities:

Employee – Represents institutional staff members with attributes like employee ID, name, salary, department, and a list of technical skills.

Instructor – Represents a specialized employee who delivers courses. It contains identification and contact information like name, email, and phone number.

Course – Represents academic courses offered by the institution, each having a course ID, name, number of credits, and an associated instructor.
